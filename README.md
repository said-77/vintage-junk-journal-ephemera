# L'Atelier Slow Fashion & Patterns

Curated printable PDF sewing patterns, linen fashion templates, and step-by-step tutorials for women, mature 45+, and cozy kids clothing.

## Features
- **Instant Digital Download**: High-resolution vector PDF templates (A4, US Letter, Projector files).
- **Multi-Size Grading**: Detailed sizing charts from XS to XXL with 1.5 cm seam allowances included.
- **Mobile-First Aesthetic**: Designed with clean, autonomous HTML5 & CSS3 in Kinfolk/Toast minimal style.
- **Affiliate Partner**: Powered by [Creative Fabrica](https://www.creativefabrica.com/ref/29590294/) (Affiliate ID: 29590294).

## Structure
- `index.html` — Semantic, responsive landing page.
- `style.css` — Custom linen aesthetic stylesheet.
- `test_bridge.py` — Quality assurance and link integrity test suite.
